# Teófilos - Site Institucional

Réplica e modernização do site institucional da **Teófilos** (Empresa Júnior da Universidade Estadual de Maringá - UEM).

## 🚀 Tecnologias

- **React 19** + **Vite 7**
- **GSAP 3** + **ScrollTrigger** (animações de entrada e scroll)
- **Lenis** (rolagem suave)
- **@fontsource** (fontes servidas localmente: Playfair Display, Plus Jakarta Sans, Outfit)
- **Sharp** (otimização de imagens para formato moderno WebP)

## 📦 Como rodar localmente

```bash
# 1. Instalar as dependências
npm run build:install

# 2. Iniciar o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no seu navegador.

## 🛠️ Comandos disponíveis

- `npm run dev`: Inicia o ambiente de desenvolvimento.
- `npm run build`: Gera o build estático otimizado em `frontend/dist`.
- `npm run preview`: Visualiza o build de produção localmente.
